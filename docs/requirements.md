# StockTrace 需求说明

## 1. 产品定位

StockTrace 是一个面向中国 A 股的本地轻量跟踪系统，核心目标是维护股票池、定时采集行情与低频指标、生成事件型信号，并通过 Web / CLI 查看结果。

当前要求实现单机版研究工具，不包含交易、账户、权限和云端协作能力。

## 2. 当前范围

### 2.1 实现目标

- 维护本地股票池，数据存储在 SQLite。
- 支持通过股票代码、股票名称或简称关键词添加股票。
- 支持批量输入添加股票。
- 每 30 分钟同步一次盘中快照。
- 同步沪市 / 深市宏观快照。
- 支持手动或定时刷新分红、财报、120 日日线资金流、日 K、MA20 / MA60。
- 基于快照差分生成事件型信号。
- 支持按日补信号，弥补盘中快照缺失。
- 支持邮件发送未通知过的新信号。
- 提供 Flask Web 页面与 CLI 两套入口。

### 2.2 当前非目标

- 自动交易或下单。
- 多用户、登录、权限。
- 云端部署后的账号体系。
- 历史回测。
- 完整财务因子体系。

## 3. 用户与使用场景

| 角色 | 使用场景 |
|---|---|
| 个人投资研究用户 | 维护关注股票、看快照、看信号、接收邮件提醒 |
| 开发者 | 调整数据源、指标口径、调度和页面展示 |
| Review / 审计人员 | 根据代码核对口径、数据流和功能边界 |

## 4. 功能需求

### 4.1 股票池管理

系统支持添加股票，不支持删除、禁用或分组管理。

支持输入：

- 6 位股票代码，如 `600519`
- 股票名称，如 `贵州茅台`
- 简称关键词，如 `茅台`
- 批量输入，如 `600519, 三七互娱, 华钰股份`

支持分隔符：

```text
英文逗号、中文逗号、顿号、分号、换行、制表符
```

解析规则：

- 优先走腾讯 smartbox 搜索。
- 搜索失败时，若输入是数字，则按 6 位代码标准化。
- 对名称搜索会尝试去掉后缀 `股份 / 股票 / 证券 / 集团 / 有限` 后再搜索。
- 无法匹配时返回友好错误。

### 4.2 盘中快照同步

每次盘中同步会：

1. 先尝试同步沪市 / 深市宏观快照。
2. 拉取股票池的腾讯实时行情。
3. 结合本地低频缓存，计算股息率、ROE、资产负债率、动态 PE、MA 偏离和趋势状态。
4. 优先使用百度分钟级资金流填充主力净流入，失败时回落到本地日级资金流。

盘中快照字段包括：

| 字段 | 说明 |
|---|---|
| code / name | 股票代码、名称 |
| snapshot_time | 快照时间 |
| price / change_pct | 现价、涨跌幅 |
| turnover_pct | 换手率 |
| amount_wan | 成交额，万元 |
| volume_ratio | 量比 |
| pe_static / pe_ttm | 静态 PE、滚动 PE |
| pe_dynamic / pe_dynamic_source | 动态 PE 及来源 |
| pb | 市净率 |
| market_cap_yi / float_market_cap_yi | 总市值 / 流通市值，亿元 |
| dividend_yield_ttm | 股息率 TTM |
| roe | 最近一期年化 ROE |
| ma20 / ma60 | 最新 MA20 / MA60 |
| dist_ma20_pct / dist_ma60_pct | 相对 MA20 / MA60 的偏离 |
| trend_status | 趋势状态文案 |
| debt_to_asset_ratio | 资产负债率 |
| main_net_in / main_net_in_source | 主力净流入及来源 |

### 4.3 低频刷新

依次刷新：

- 分红历史
- 日级资金流
- 最近一期财报
- 日 K 与日级指标

失败策略：

- 单只股票、单项低频数据失败不会中断整个任务。
- CLI / Scheduler 会打印失败原因。
- Web 端低频刷新会吞掉异常，页面只显示最终同步结果。

### 4.4 宏观快照

系统会同步两个市场的宏观快照：

- 沪市：上证指数
- 深市：深证成指

同步内容包括：

- 指数点位
- 涨跌点
- 涨跌幅
- 最高 / 最低
- 成交额
- 上涨 / 下跌 / 平盘 / 总家数

首页展示最新沪深市场概览，`/macro` 展示最近 200 条历史记录。

### 4.5 信号生成

信号生成入口：

- 调度器盘中同步后自动执行
- CLI `sync` 后自动执行
- Web `/sync` 后自动执行

信号采用“事件差分”机制：

- 对普通状态，只在“当前有、上一条没有”时生成一次。
- 对穿越型事件，必须比较前后两条数据，避免已有状态被重复当成新信号。
- 第一条快照只做基线，不生成信号。

信号列表：

| 信号类型 | 触发条件 | 级别 |
|---|---|---|
| 放量上涨 | 10:00 后，量比 `>= 2.0` 且涨幅 `>= +2%` | 中 |
| 放量下跌 | 10:00 后，量比 `>= 2.5` 且跌幅 `<= -2%` | 高 |
| 主力净流入 | 10:00 后，主力净额 / 成交额 `>= +8%` | 低 |
| 主力净流出 | 10:00 后，主力净额 / 成交额 `<= -8%` | 低 |
| 高股息（健康） | 股息率 `>= 5%` 且未跌破 MA60 | 低 |
| 高股息（破位） | 股息率 `>= 5%` 且跌破 MA60 | 中 |
| 金叉 | MA20 相对 MA60 由 `<= 0` 变为 `> 0` | 高 |
| 死叉 | MA20 相对 MA60 由 `>= 0` 变为 `< 0` | 高 |
| 站上 MA60 | 距 MA60 由 `< +1%` 升到 `>= +1%` | 中 |
| 跌破 MA60 | 距 MA60 由 `> -1%` 跌到 `<= -1%` | 高 |
| 乖离过热 | 距 MA20 由 `< +15%` 升到 `>= +15%` | 中 |
| 乖离超卖 | 距 MA20 由 `> -15%` 跌到 `<= -15%` | 中 |

### 4.6 信号补算

系统支持在缺失盘中快照时按日粒度补信号。

入口：

- CLI `python -m app.cli regen-signals 2026-05-28`
- Web `/backfill`

补算规则：

- `regen-signals` 基于某一日的盘中快照序列重算该日信号，可先删旧数据再重建。
- `/backfill` 基于 `daily_quote` + `daily_indicator` + `fund_flow` 组合成“日线版快照”，按“当日 vs 上一交易日”补信号。
- 补出的信号时间统一记为当日 `15:00:00`。

### 4.7 邮件通知

支持邮件通知。

行为要求：

- 只发送尚未通知成功的新信号。
- 同一条信号对同一收件人成功发送后不重复发送。
- 发送成功或失败都写入 `notification_log`。
- 发送失败时，调用方会收到异常或失败提示。

通知入口：

- 调度器盘中任务结束后自动尝试发送
- CLI `python -m app.cli notify`
- CLI `python -m app.cli sync --notify`
- Web `/notify`
- Web `/sync?notify=1`

邮件配置来源优先级：

```text
环境变量 EMAIL_* > data/email_config.json
```

### 4.8 Web 页面

页面全部由 Flask 直接拼接 HTML 输出，无前端框架。

#### 首页 `/`

功能：

- 添加股票
- 立即同步
- 同步并刷新低频数据
- 查看最新沪深宏观指标
- 查看股票池最新快照
- 支持服务端排序

首页快照列：

- 代码
- 名称
- 现价
- 涨跌幅
- PE_TTM
- ROE
- PB
- 股息率 TTM
- 距 MA20
- 距 MA60
- 资产负债率
- 主力净流入（万元）

额外展示：

- 最新快照时间
- 主力净流入来源汇总

#### 个股详情 `/stock/<code>`

功能：

- 查看核心指标卡片
- 查看最近 100 条盘中快照
- 查看最近 30 条该股信号
- 支持只同步该股票
- 支持只同步该股票并刷新低频数据

#### 信号页 `/signals`

功能：

- 展示最近 200 条信号
- 展示当前信号阈值说明
- 页面上将信号级别和类型显示为中文文案

#### 宏观页 `/macro`

功能：

- 查看最近 200 条宏观快照历史

#### 快照页 `/snapshots`

功能：

- 查看最近 500 条全部股票快照历史

#### 添加接口 `/add`

功能：

- 处理首页表单提交
- 支持批量添加
- 批量添加时忽略统一自定义名称，避免误命名

#### 同步接口 `/sync`

支持参数：

- `code`：只同步一只股票
- `low_freq=1`：同步前先刷新低频缓存
- `notify=1`：同步后发送邮件通知

#### 补信号接口 `/backfill`

后端当前识别：

- `start`
- `end`

若都不传，则默认补当天。

## 5. 指标与口径

### 5.1 PE / PB / 市值 / 换手率 / 量比

来源：腾讯财经实时行情。

说明：

- `pe_ttm`、`pb`、`market_cap_yi`、`float_market_cap_yi` 直接来自腾讯行情字段。
- `dynamic_pe` 不来自外部接口，而是用本地 `valuation_forecast` 数据计算。

### 5.2 动态 PE

计算优先级：

1. `价格 / 预测 EPS`
2. `总市值(亿元) / 预测净利润(亿元)`

说明：

- 仅在本地已录入 `valuation_forecast` 时可得。
- 当前会写入快照，但首页和详情页未展示。

### 5.3 股息率 TTM

当前采用东财近似口径：

```text
近一年报告期（含预案）现金分红总额 / 最近总市值 × 100%
```

实现细节：

- 分红按 `report_date` 窗口统计，不按除权日滚动 365 天统计。
- 同一报告期若存在预案和实施多条记录，只取公告日最新的一条。
- `PRETAX_BONUS_RMB` 先由“每 10 股税前派息”换算成“每股税前派息”。

### 5.4 ROE

当前口径：

```text
最近一期累计归母净利润年化 / 最近一期股东权益 × 100%
```

年化因子：

| 报告月 | 因子 |
|---|---:|
| 3 月 | 4 |
| 6 月 | 2 |
| 9 月 | 4/3 |
| 12 月 | 1 |

### 5.5 资产负债率

```text
负债合计 / 资产总计 × 100%
```

### 5.6 MA20 / MA60 与趋势状态

当前日级指标会计算：

- MA20
- MA60
- 20 日量比
- 趋势阶段文案

趋势文案规则：

- `多头：价高于MA20，MA20高于MA60`
- `空头：价低于MA20，MA20低于MA60`
- `中性偏强：价高于MA60`
- `中性偏弱：价低于MA60`

### 5.7 主力净流入

盘中快照优先级：

1. 百度分钟级资金流 `fund_flow_realtime`
2. 本地 `fund_flow` 最近一条日级资金流

单位规则：

- 快照内统一展示万元
- 东财日级资金流落表时保留原始单位元

## 7. 调度需求

### 7.1 盘中任务

调度器使用 APScheduler，固定每 30 分钟触发一次 `intraday_job`，但仅在以下时段真正执行同步：

```text
工作日 09:30 - 11:35
工作日 13:00 - 15:10
```

特性：

- 启动后立即执行一次
- `misfire_grace_time` 为 30 分钟
- 单实例执行，避免重叠

### 7.2 低频任务

每天 `20:00` 执行一次：

- 分红刷新
- 日级资金流刷新
- 财报刷新
- 日 K / MA 刷新

`misfire_grace_time` 为 1 小时。

## 8. 运行要求

### 8.1 本地运行

Web 默认启动参数：

```text
host = 127.0.0.1
port = 5001
```

可通过 `HOST` / `PORT` 环境变量覆盖。

### 8.2 Docker 运行

容器内：

- Web 绑定 `0.0.0.0:5000`
- 调度器与 Web 由 `start.sh` 同容器启动
- `data/` 目录用于持久化 SQLite 和邮件配置
